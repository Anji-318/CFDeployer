使用说明 · 版本 v1.1.0

📖 概述

Cloudflare Deployer 是一款面向 Windows 的 WPF 桌面应用，用于批量部署 Cloudflare Worker 和 Cloudflare Pages 项目。

核心功能

  • 独立配置管理：保存多个 Worker / Pages 部署配置
  • 账户组管理：批量管理多个 Cloudflare 账号
  • Worker 模板：支持变量替换的 Worker 代码模板
  • 部署矩阵：账户 × 变量的组合批量部署
  • Cloudflare Pages 部署：直连 api.cloudflare.com，无需代理
  • 代码处理工具：分析、Base64/Unicode/Hex 编解码、混淆、格式化
  • 代理中转：Worker 部署可通过自建的 Cloudflare Worker 代理绕过 CORS
部署目标对比
特性 Worker 部署 Pages 部署
是否需要代理 ✅ 必须 ❌ 不需要
API 端点 自建代理 Worker api.cloudflare.com
批量并发建议 3 1-2
部署间隔 无 ≥ 1 秒

🚀 安装与运行

环境要求

  • Windows 10 / Windows 11
  • .NET 8.0 SDK 或更高版本

编译运行

# 进入项目目录
cd CFDeployer

# 编译
dotnet build

# 运行
dotnet run

# 发布单文件（可选）
dotnet publish -c Release
注意：项目 global.json 默认要求 .NET 8 SDK。如果本地只安装了 .NET 9 SDK，可将 rollForward 改为 latestMajor。

🌐 代理配置（Worker 部署必需）

由于 Cloudflare Worker 部署 API 使用 multipart/form-data，在 WPF 桌面应用中直接调用会受 CORS 限制，因此 Worker 部署必须通过一个中间代理 Worker 转发。

配置步骤

  1. 在 Cloudflare 上创建一个代理 Worker，暴露 /deploy/single 端点
  2. 代理 Worker 将请求转发到 https://api.cloudflare.com/client/v4/accounts/{account_id}/workers/scripts/{worker_name}
  3. 打开 Cloudflare Deployer，点击顶部代理状态按钮
  4. 在弹窗中填入代理 Worker URL（如 https://your-proxy.your-subdomain.workers.dev）
  5. 如果代理有访问密钥，填入可选的密钥
提示：Pages 部署直连 Cloudflare API，不需要配置代理。
安全提醒：API Token 当前以明文形式存储在 %AppData%/CFDeployer/data.json 中。请勿在公共或不安全的计算机上保存敏感 Token。

⚙️ Worker 部署

1. 创建独立配置

  1. 切换到 👤 配置管理 Tab
  2. 点击 + 新建配置
  3. 填写配置名称、Account ID、API Token、Worker 名称
  4. 在 Worker 代码区域编辑或粘贴代码
  5. 点击 🚀 部署当前配置

2. 配置字段说明

字段 说明 是否必填
配置名称 本地显示名称 是
Account ID Cloudflare 账户 ID 是
API Token 具有 Cloudflare Workers 编辑权限的 Token 是
Worker 名称 目标 Worker 脚本名称 是
自定义域名 可选，部署后绑定自定义域名 否
Secrets 加密变量（通过 Worker 密钥管理） 否
环境变量 明文环境变量 否
Worker 代码 JavaScript / TypeScript Worker 代码 是

3. API Token 权限要求

Worker 部署需要 Token 拥有以下权限：

  • Cloudflare Workers:Edit
  • Account:Read
  • 如需自定义域名：Zone:Edit（对应域名区域）

📄 Pages 部署

Cloudflare Pages 部署通过 Direct Upload API 直连 api.cloudflare.com，不需要代理。

1. 创建 Pages 项目

  1. 切换到 📄 Pages项目 Tab
  2. 点击 + 新建项目
  3. 填写显示名称、Account ID、API Token、Cloudflare Pages 项目名
  4. 选择分支（默认 main）和部署类型
  5. 可选：填写静态文件目录，或点击右侧 浏览... 按钮选择本地文件夹
  6. 可选：填写 Worker 代码（Pages Function 模式）
  7. 点击 🚀 部署当前 Pages 项目

2. 部署类型说明

类型 说明 适用场景
直接上传 直接上传静态文件生成 Deployment 纯静态网站、SPA、文档站
Pages Function（含 Worker） 上传静态文件的同时包含 _worker.js 需要后端逻辑的 Pages 项目

3. 静态文件目录

  • 填写本地文件夹路径，如 C:\Users\Giga\Sites\my-site
  • 或点击文本框右侧的 浏览... 按钮打开文件夹选择对话框
  • 目录中的所有文件将按相对路径上传到 Pages
  • 如果留空，系统会上传一个默认的 index.html

4. Worker 代码（Pages Function）

选择 Pages Function 模式时，代码区域的内容将作为 _worker.js 上传。代码示例：

export default {
  async fetch(request, env, ctx) {
    return new Response("Hello from Pages Function!");
  }
};

5. API Token 权限要求

Pages 部署需要 Token 拥有以下权限：

  • Cloudflare Pages:Edit
  • Account:Read

🚀 矩阵批量部署

矩阵部署用于一次将同一套代码/模板部署到多个账户或多个变量组合。

Worker 矩阵部署

  1. 切换到 🚀 部署矩阵 Tab
  2. 选择账户组
  3. 选择Worker 模板
  4. 在变量配置中输入变量值，用逗号分隔，如 us-east,us-west,eu-central
  5. 矩阵预览会显示所有 账户 × 变量 组合
  6. 点击选择要部署的任务，或点击全选
  7. 点击 🚀 开始批量部署

Pages 矩阵部署

  1. 切换到 📄 Pages项目 Tab
  2. 在右侧下方的 🚀 Pages 矩阵部署 区域选择账户组
  3. 填写项目名模式，支持变量占位符，如 demo-pages-{{region}}
  4. 在变量配置中输入变量值，用逗号分隔
  5. 矩阵预览会显示所有 账户 × 变量 组合
  6. 点击 🚀 开始批量部署

矩阵部署示例

场景：单账户多 Pages 项目

  • 账户组：选择包含 1 个账户的组
  • 项目名模式：pages-{{region}}
  • region 变量：us,eu,asia
  • 生成任务：pages-us、pages-eu、pages-asia

场景：多账户单 Pages 项目

  • 账户组：选择包含 3 个账户的组
  • 项目名模式：demo-site（无变量）
  • 生成任务：3 个账户都部署到 demo-site
Pages 矩阵限流保护：Pages 部署默认串行（并发=1），每个任务完成后间隔 1 秒。如果遇到 429 限流，会自动指数退避重试 3 次。大量 Pages 项目部署建议分批执行。

📋 Worker 模板

模板用于在矩阵部署中批量生成不同名称或不同变量的 Worker。

创建模板

  1. 切换到 ⚙️ Worker模板 Tab
  2. 点击 + 新建模板
  3. 填写模板名称
  4. 设置 Worker 名称模式，如 worker-{{region}}
  5. 在变量定义中添加变量名，如 region
  6. 编辑代码模板，使用 {{region}} 占位符

模板变量

变量在代码和名称模式中均可使用：

// Worker 名称模式
worker-{{region}}

// 代码中的变量
code = code.Replace("{{region}}", "us-east");

🛠️ 代码处理工具

在配置管理页和模板编辑页的代码区域上方，提供以下工具按钮：

按钮 功能
🔍 分析 分析代码行数、注释数、复杂度、常用模式
🔓 解码 ▼ Base64 / Unicode / Hex 解码
🔒 混淆 ▼ Base64 编码、轻度混淆、中度混淆
📝 格式 ▼ 格式化代码、压缩代码
注意：混淆和压缩是不可逆操作，建议在操作前先备份原始代码。

💾 数据管理

数据存储位置

所有配置、账户组、模板、Pages 项目数据保存在：

%AppData%/CFDeployer/data.json

导出配置

点击底部状态栏的 📤 导出 按钮，可将所有数据导出为 JSON 文件备份。

导入配置

点击底部状态栏的 📥 导入 按钮，可从 JSON 文件恢复数据。

重置数据

点击底部状态栏的 🗑️ 重置 按钮，将清空所有本地数据。此操作不可恢复。

重要：重置会删除所有配置、账户组、模板和 Pages 项目。重置前请先导出备份。

🔧 常见问题

Worker 部署提示 "代理URL未配置"

Worker 部署必须通过代理 Worker 中转。请先在顶部代理警告栏配置代理 Worker URL。

Pages 部署提示 "429 Too Many Requests"

Cloudflare Pages API 有请求频率限制。建议：

  • 降低 Pages 矩阵部署的任务数量
  • 每次部署间隔已自动设为 1 秒
  • 大批量部署建议分批执行，每批之间休息 1-2 分钟

部署失败但日志显示 HTTP 错误

请检查：

  • Account ID 和 API Token 是否正确
  • API Token 是否拥有足够的权限
  • Worker 名称 / Pages 项目名是否符合 Cloudflare 命名规则
  • 代理 Worker 是否正确部署（Worker 部署）

矩阵预览没有生成任务

请检查：

  • 账户组中是否添加了账户
  • 模板变量是否填写了值（用逗号分隔）
  • Pages 项目名模式是否正确使用了 {{variable}} 格式

如何切换深色/浅色主题

点击顶部标题栏右侧的 🌙 / ☀️ 按钮即可切换主题。
